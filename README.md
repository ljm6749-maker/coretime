# 한화비전 글로벌 코어타임

한화비전 6개 지역 법인(한국·북미·중남미·유럽·중동·싱가포르)의 **실시간 현지시각**을 세계지도 위에 표시하고,
회의 개최일자와 참여 법인을 고르면 **해당 분기의 글로벌 코어타임 기준**으로 최적 회의시간을 찾아주는 웹사이트입니다.

빌드 도구·서버·외부 라이브러리 없이 동작하는 정적 사이트입니다.

## 실행

```bash
python3 -m http.server 8000     # 저장소 루트에서 실행 후 http://localhost:8000
```

파일 하나로 배포해야 한다면:

```bash
python3 build.py                # dist/index.html (CSS·JS 인라인 단일 파일)
```

## 화면 구성

| 영역 | 내용 |
| --- | --- |
| 글로벌 네트워크 지도 | 세계지도 위 6개 법인 마커 + 실시간 현지시각. 지도 명암은 실제 태양 위치로 계산한 낮/밤 |
| 회의 플래너 | 개최일자 · 기준 시간대 · 소요시간 · 참여 법인 선택 → 추천 회의시간 5개, 법인별 판정표, 하루 전체 히트맵 |
| 분기 코어타임 | 선택한 날짜가 속한 분기의 법인별 코어타임 · 확장 가능 시간 |

### 판정 기준

| 표시 | 의미 |
| --- | --- |
| 코어타임 | 회의 시작~종료가 그 법인의 분기 코어타임 안에 들어옴 |
| 확장 가능 | 코어타임은 벗어나지만 확장 가능 시간 안 — 사전 협의 필요 |
| 근무시간 밖 | 확장 가능 시간도 벗어남 (심야 포함) |
| 휴무일 | 현지 기준 주말/휴무 |

추천 순위는 참여 법인의 상태별 벌점 합계가 낮은 순이며, 인접한 후보가 상위권을 독식하지 않도록 최소 90분 간격으로 골라 보여줍니다.
시차가 커서 전원이 근무시간 안에 모일 수 없는 조합(예: 중남미 ↔ 아시아)은 그 사실을 명시하고,
시차가 가장 크게 벌어지는 지점에서 두 그룹으로 나눈 **분할 회의 제안**을 함께 제시합니다.

## 기준값 관리

모든 기준값은 [`assets/js/data.js`](assets/js/data.js) 한 곳에 있습니다.

* `ENTITIES` — 법인 목록. 이름·법인명·도시·IANA 시간대·지도 좌표(위경도)·근무요일·점심시간
* `CORE_TIME_POLICY` — 분기(Q1~Q4)별 법인 코어타임(`core`)과 확장 가능 시간(`extended`). 시간은 각 법인 **현지시간** 기준(`8.5` = 08:30)

분기별 코어타임 값은 각 법인의 정규 근무시간과 분기 운영 특성(1분기 사업계획 정렬, 2분기 표준,
3분기 하계 유연근무, 4분기 결산)을 반영한 **기준안**입니다. 사내 확정 코어타임 공지가 있으면 이 표만 교체하면
지도·추천·히트맵 계산에 모두 반영됩니다.

법인을 추가하려면 `ENTITIES`에 항목을 넣고 `CORE_TIME_POLICY`의 각 분기 `windows`에 같은 `id`를 추가하면 됩니다.

## 구현 메모

* **시간대** — `Intl.DateTimeFormat`으로 각 시점의 UTC 오프셋을 직접 계산하므로 서머타임(DST)이 자동 반영됩니다. 별도 라이브러리가 없습니다. (`assets/js/tz.js`)
* **지도** — Natural Earth 기반 국가 경계 데이터를 0.75° 격자로 샘플링한 육지 비트마스크(`assets/js/world-mask.js`, 약 15KB)를 캔버스에 정방형 도법으로 도트 렌더링합니다. 외부 타일 서버나 이미지 요청이 없습니다.
* **낮/밤** — 태양 직하점(적위·균시차)을 계산해 각 도트의 태양 고도로 낮·박명·밤을 구분합니다. (`assets/js/map.js`)
* **추천 로직** — `assets/js/scheduler.js`. 기준 법인 현지 00:00~24:00을 30분 간격으로 훑으며 후보를 평가합니다.

## 알려진 제약

* 공휴일은 반영되어 있지 않습니다. 주말(법인별 `workdays`)과 중동 법인의 금요일 예배 시간만 반영합니다.
* 법인 소재지는 대표 사무소 기준이며, 같은 지역 내 복수 거점은 하나로 표시합니다.

## 파일 구조

```
index.html                 화면 마크업
assets/css/styles.css      스타일
assets/js/data.js          법인 정보 · 분기별 코어타임 정책   ← 기준값 수정은 여기
assets/js/tz.js            시간대 유틸리티 (DST 자동 반영)
assets/js/scheduler.js     회의시간 추천 엔진
assets/js/map.js           세계지도 렌더링 · 마커 · 실시간 시계
assets/js/app.js           화면 조립 · 상태 관리
assets/js/world-mask.js    육지 도트 비트마스크 (생성 데이터)
build.py                   단일 파일 빌드 (dist/index.html)
```
