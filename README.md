# 한화비전 글로벌 코어타임

한화비전 6개 지역 법인(한국·북미·중남미·유럽·중동·싱가포르)을 위한 **월드타임버디 방식 회의시간 도구**입니다.
세계지도 위에 각 법인의 실시간 현지시각과 휴무 여부를 표시하고, 날짜와 참여 법인을 고르면
**해당 분기 글로벌 코어타임**을 붉은 음영으로 깐 시간표에서 회의시간을 바로 고를 수 있습니다.
고른 시각은 회의 소집 메일 초안(국문·영문)으로 바로 복사됩니다.

빌드 도구·서버·외부 라이브러리 없이 동작하는 정적 사이트입니다.

## 실행

```bash
python3 -m http.server 8000     # 저장소 루트에서 실행 후 http://localhost:8000
python3 build.py                # 단일 파일 배포본 dist/index.html
```

## 화면 구성

| 영역 | 내용 |
| --- | --- |
| 글로벌 네트워크 지도 | 세계지도 위 6개 법인 마커 + 실시간 현지시각 · 공휴일 표시. 명암은 실제 태양 위치로 계산한 낮/밤. 선택한 회의 시각 기준으로 전환 가능 |
| 회의 시간표 | 행=법인, 열=기준 법인의 0~23시. **붉은 칸이 코어타임**, 주황 칸은 확장 가능, 빗금 칸은 휴무·공휴일. 칸을 클릭하면 그 시각으로 회의 설정 |
| 추천 회의시간 | 30분 단위 후보를 벌점 순으로 4개 제시. 전원 참석이 불가능한 시차 조합이면 두 그룹으로 나눈 분할 회의안 제시 |
| 회의 소집 메일 | 선택한 시각이 반영된 국문/영문 메일 초안. 제목+본문 한 번에 복사 |
| 분기 코어타임 | 적용 중인 분기 코어타임과 **다음 분기 변경 예정**(확대/축소/이동)을 나란히 비교 |

### 판정 기준

| 표시 | 의미 |
| --- | --- |
| 코어타임 (붉은 음영) | 회의 시작~종료가 그 법인의 분기 코어타임 안 |
| 확장 가능 | 코어타임 밖이지만 확장 가능 시간 안 — 사전 협의 필요 |
| 근무시간 밖 | 확장 가능 시간도 벗어남 (심야 포함) |
| 휴무 · 공휴일 (빗금) | 현지 기준 주말 또는 공휴일 |

추천 순위는 참여 법인의 상태별 벌점 합계가 낮은 순이며, 인접 후보가 상위권을 독식하지 않도록 최소 90분 간격으로 고릅니다.
현지 점심시간과 겹치는 시각, 중동 법인의 금요일 예배 시간도 벌점에 반영됩니다.

## 기준값 관리 — 수정은 이 두 파일만

### `assets/js/data.js`

* `ENTITIES` — 법인 목록(이름·법인명·도시·IANA 시간대·지도 좌표·근무요일·점심시간)
* `CORE_TIME_POLICY` — 분기(Q1~Q4)별 코어타임 `core` / 확장 가능 `extended`. 각 법인 **현지시간** 기준이며 `8.5` = 08:30
* `HOLIDAYS` — 법인별 공휴일(2026년). 음력·이슬람력 기반 휴일은 `{ name, tentative: true }`로 두면 화면에 *잠정*으로 표시됩니다

분기별 코어타임 값은 각 법인 정규 근무시간과 분기 운영 특성(1분기 사업계획 정렬, 2분기 표준, 3분기 하계 유연근무,
4분기 결산)을 반영한 **기준안**입니다. 사내 확정 공지가 나오면 이 표만 교체하면 지도·시간표·추천·메일 초안에 모두 반영됩니다.

### `assets/js/mail.js`

* `MAIL_FIELDS` / `MAIL_FIELDS_EN` — 메일 초안의 자리표시자(회의명·참석 대상·안건·링크·서명)
* `bodyKo` / `bodyEn` — 본문 문구 자체

## 구현 메모

* **시간대** — `Intl.DateTimeFormat`으로 각 시점의 UTC 오프셋을 계산하므로 서머타임(DST)이 자동 반영되고, 시간표 라벨에 `DST` 배지가 붙습니다. (`assets/js/tz.js`)
* **지도** — Natural Earth 기반 국가 경계를 0.75° 격자로 샘플링한 육지 비트마스크(`assets/js/world-mask.js`, 약 15KB)를 캔버스에 정방형 도법으로 도트 렌더링합니다. 외부 타일 서버·이미지 요청이 없습니다.
* **낮/밤** — 태양 직하점(적위·균시차)을 계산해 도트별 태양 고도로 낮·박명·밤을 구분합니다. (`assets/js/map.js`)
* **추천 로직** — `assets/js/scheduler.js`. 기준 법인 현지 00:00~24:00을 30분 간격으로 훑으며 후보를 평가합니다.

## 알려진 제약

* 공휴일 표는 2026년 기준 수기 입력이며, 음력·이슬람력 휴일은 확정 공고 전 잠정값입니다.
* 법인 소재지는 대표 사무소 기준이며, 같은 지역 내 복수 거점은 하나로 표시합니다.
* 개인 일정·회의실 예약과는 연동되지 않습니다.

## 파일 구조

```
index.html                 화면 마크업
assets/css/styles.css      스타일
assets/js/data.js          법인 · 분기 코어타임 · 공휴일     ← 기준값 수정
assets/js/mail.js          회의 소집 메일 템플릿             ← 문구 수정
assets/js/tz.js            시간대 유틸리티 (DST 자동 반영)
assets/js/scheduler.js     회의시간 추천 엔진
assets/js/map.js           세계지도 렌더링 · 마커 · 실시간 시계
assets/js/app.js           화면 조립 · 상태 관리
assets/js/world-mask.js    육지 도트 비트마스크 (생성 데이터)
build.py                   단일 파일 빌드 (dist/)
```
